网页 ADB 工具

浏览器直接走 WebUSB 跟手机说话，执行 adb 命令启动 Shizuku 和 黑域（Brevent）。不装 adb，不敲命令行。所有命令都在你的浏览器和手机之间完成， 这个页面没有后端，也不上传任何数据。

用之前要注意什么
  1. 浏览器必须是桌面版 Chrome 或 Edge（WebUSB 只有 Chromium 系有；Firefox、Safari、手机浏览器都不行）。
  2. 页面必须是 https 打开（本站就是），本地直接双击 HTML 文件不行。
  3. 手机打开「开发者选项 → USB 调试」，插上数据线，手机上弹「允许 USB 调试」时勾上「始终允许」。
  4. 电脑上的 adb server 或 Android Studio 会独占手机，WebUSB 就抢不到了。先执行 adb kill-server 或关掉相关软件。
  5. Windows 需要把手机的 ADB 接口换成 WinUSB 驱动（用 Zadig），否则浏览器读不到设备；macOS / Linux 免驱动。
  6. 手机上装好 Shizuku 和 黑域。Shizuku 建议先打开过一次；黑域不用（激活走的是 app_process，不需要它导出任何脚本）。
  7. 两种方式启动的服务都是临时的，手机重启后要重新启动一次。
连不上 / 启动失败怎么排查
  • 点「连接手机」没弹窗：检查地址栏右侧是否被浏览器拦了设备权限弹窗，或换个 USB 口、换根线。
  • 提示设备被占用：adb kill-server，关掉 Android Studio、投屏、手机助手类软件，再重连。
  • Windows 报 transfer error：用 Zadig 给手机的 ADB 接口装 WinUSB 驱动（装了厂商驱动的电脑常见）。
  • Shizuku 没启动：把 Shizuku 更新到 v13.6 以上，或先在手机上打开 Shizuku 应用再重试。
  • 黑域没启动：本工具按黑域官方方式激活（app_process 加载 apk 里的服务类）。如果日志里没有 brevent 进程，常见原因是黑域版本过旧——升到现行 4.x 再试。另一个办法：Shizuku 起来之后，直接在黑域应用内按提示用 Shizuku 启动，不用数据线。
  • 确认服务是否起来了，手动执行：ps -A -o NAME | grep -E "shizuku|brevent"。
背后的命令（想看原理的点这里）
  • Shizuku（v13.6+）：pm path moe.shizuku.privileged.api 拿到安装目录，执行其中的 libshizuku.so。
  • Shizuku（v11.2+ 旧方式）：sh /storage/emulated/0/Android/data/moe.shizuku.privileged.api/start.sh。
  • 黑域（官方方式，见 brevent.sh）：把 pm path me.piebridge.brevent 给出的 base.apk 设为 CLASSPATH，执行 app_process /system/bin me.piebridge.brevent.server.BreventServer bootstrap，它生成并执行 /data/local/tmp/brevent.sh 把服务常驻起来。老版本（3.x）才用存储目录里的 brevent.sh，找不到时工具会自动退回那条路。
  • 底层用的是 Tango ADB（ya-webadb），纯浏览器实现的 ADB 协议，MIT 协议。
